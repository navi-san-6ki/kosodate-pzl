# こそだてパズル

子どもの人数・年齢・できることと家庭の状況に合わせて、育児の段取りを組み立て直せる無料Webアプリです。

## 現在の公開ベータ

- 複数の子どもを登録
- 年齢と「できること」を設定
- 外出・食事・入浴・寝かしつけのシーンを切り替え
- タスクの完了と、雨・ぐずり・昼寝・予定遅延による組み直し
- 家族情報をブラウザの端末内に保存

ログイン、データベース、外部APIは使っていません。家族情報は利用している端末のブラウザに保存されます。

## 開発

```bash
pnpm install
pnpm --filter @workspace/kosodate-puzzle run dev
```

本番向けの静的ビルドは次のコマンドで作成できます。

```bash
pnpm --filter @workspace/kosodate-puzzle run build
```

## 今後の拡張

本番では、オムツ替え、親の睡眠、洗濯、料理、ゴミ出し、宅配の段ボール整理、買い物を育児タスクと同じボードで扱い、「洗濯しながら料理」のような並行作業にも対応する予定です。
