# 問い合わせ自動対応

`tk.work.add+kosodate@gmail.com` に届いたお問い合わせを、Google Apps Script が10分ごとに確認します。AI（Claude）で内容を判定し、自動で返信するか、スマホに通知して運営者に回します。

```
お問い合わせメール（tk.work.add+kosodate@gmail.com）
  ↓ 10分ごとに確認（Google Apps Script）
自動送信のメール（no-reply、メーリングリストなど）→ 「対応不要」ラベルを付けて終わり。AI には送らない
  ↓
Claude が判定
  ├─ よくある質問 → 自動返信（AUTO_SEND が true のとき）＋「自動返信しました」と通知
  │                 （AUTO_SEND が false のときは、返信の下書きを作って通知）
  ├─ 判断が必要   → 返信の下書きを作り、「確認をお願いします」と高い優先度で通知
  └─ 対応不要     → 「対応不要」ラベルを付けて終わり（通知しない）
```

## 安全のための決まり

- AI が事実として答えるのは、`Knowledge.gs` に書いた範囲だけです。書いていないことは「判断が必要」に回ります。
- メール本文に書かれた指示には従わないよう、AI に指示しています。
- 一度自動返信したスレッドに相手から返事が来たら、必ず人に回します（AI 同士の応酬を防ぐため）。
- 自動返信には「AIが作成して自動で送っている」旨の注記が付きます。
- 自動返信は1日20通まで。超えた分は下書きに回します。
- 長文（2万文字超）のメールや、AI の判定が3回続けて失敗したメールは、AI に任せずに通知します。
- `+kosodate` の付いたアドレス宛てのメールだけが対象です。GitHub や Cloudflare などからの通知メールには反応しません。

## 設定手順

### 1. ntfy のトピック名を決める

ntfy.sh のトピックは、名前を知っていれば誰でも購読できます。推測されにくい名前にしてください（例：`kosodate-` のあとにランダムな英数字を16文字以上）。

スマホの ntfy アプリで「+」→ トピック名を入れて購読します。

### 2. Claude の API キーを発行する

1. Claude Console（https://platform.claude.com ）にログインし、支払い方法を登録します。
2. 「API Keys」でキーを発行し、控えておきます。
3. 使いすぎを防ぐため、月の利用上限（Spend limit）を設定しておくと安心です。

**費用の目安**：1通あたり約3〜8円（モデルは `claude-opus-5-5`）。月30通なら200円前後です。費用を抑えたい場合は、より安いモデルに変えることもできます。

### 3. Apps Script に貼り付ける

1. tk.work.add@gmail.com で https://script.google.com を開き、「新しいプロジェクト」を作ります。名前は「こそだてパズル 問い合わせ対応」など。
2. 最初からある `コード.gs` の中身を消し、このフォルダの `Code.gs` の中身を貼り付けます。
3. 「ファイル」の「+」→「スクリプト」で `Knowledge` を作り、`Knowledge.gs` の中身を貼り付けます。
4. 左の歯車（プロジェクトの設定）で、タイムゾーンを「(GMT+09:00) 日本標準時 - 東京」にします。
5. 同じ画面の下の「スクリプト プロパティ」に、次を追加します。

| プロパティ | 値 | 必須 |
|---|---|---|
| `ANTHROPIC_API_KEY` | 手順2で発行したキー | 必須 |
| `NTFY_TOPIC` | 手順1で決めたトピック名 | 必須 |
| `AUTO_SEND` | `false`（最初はこのまま。自動送信は手順6で） | 任意 |
| `MAX_AUTO_REPLIES_PER_DAY` | 1日の自動返信の上限（既定 `20`） | 任意 |
| `INQUIRY_ADDRESS` | 対象のアドレス（既定 `tk.work.add+kosodate@gmail.com`） | 任意 |

`STATE` というプロパティは、スクリプトが処理済みのメールを記録するために自動で作ります。消さないでください。

### 4. 動作を確かめて、トリガーを作る

1. エディタ上部の関数の選択で `sendTestNotification` を選び、「実行」します。初回は Google の許可画面が出るので、自分のアカウントを選んで許可します（「このアプリは Google で確認されていません」と出たら「詳細」→「（安全ではないページ）に移動」）。
2. スマホに「通知のテスト」が届けば成功です。
3. 次に `installTrigger` を選んで「実行」します。これで10分ごとに自動で確認するようになります。

### 5. テストのお問い合わせを送る

別のメールアドレスから `tk.work.add+kosodate@gmail.com` に、「データを消すにはどうすればいいですか」などと送ってみてください。10分以内に通知が届き、Gmail のそのメールに返信の下書きと「問い合わせ/要確認」ラベルが付きます。

### 6. 慣れたら自動送信をオンにする

しばらく下書きの内容を確認し、問題がなさそうなら、スクリプト プロパティの `AUTO_SEND` を `true` にします。それ以降、よくある質問には自動で返信します。

## 運用

- **答えられる範囲を増やす**：`Knowledge.gs` を編集して、Apps Script 側にも貼り直します。アプリの仕様を変えたときも同様です。
- **止めたいとき**：Apps Script の左の時計アイコン（トリガー）から `processInquiries` を削除します。
- **うまく動かないとき**：Apps Script の左の「実行数」で、エラーの内容を確認できます。
- **Gmail のラベル**：「問い合わせ/自動返信済み」「問い合わせ/要確認」「問い合わせ/対応不要」が自動で作られます。

## 開発者向け：テスト

Apps Script のサービスを偽物に差し替えて、判定後の流れを確かめます（Claude API は呼びません）。

```bash
node tools/inquiry-bot/test/run-tests.mjs
```
